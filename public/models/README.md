# Runtime character model

`soldier.glb` is the animated Soldier model distributed with the official
Three.js skeletal-animation blending example:

- Source: https://github.com/mrdoob/three.js/blob/dev/examples/models/gltf/Soldier.glb
- Example: https://threejs.org/examples/webgl_animation_skinning_blending.html
- Original model credit shown by the example: Mixamo

The game clones the skinned rig locally and applies original runtime materials
and mesh attachments to create the survivor and zombie archetypes. It does not
load character assets from a remote server while playing.
